# الجزء ٠١ — الـ lexer

شغّل الأول، قبل ما تكتب أي حاجة:

| | |
|---|---|
| **ويندوز** | دبل كليك على `run.bat` |
| **ماك / لينكس** | `./run.sh` |

هيطلعلك:

```
TokenMgrError: Lexical error at line 1, column 5.  Encountered: 'x'
```

السطر الأول في `test.txt` هو `int x = 42;` والعمود الخامس هو `x`.
يعني الأداة عرفت `int` ووقفت عند `x`.

**ده مش عطل. ده أول سؤال.**

---

## الملفات — مين فين

| الملف | إيه ده |
|---|---|
| **`Lexer.jj`** | 🔴 **ده اللي بتكتب فيه، وده اللي بتسلّمه.** مفيش غيره |
| **`test.txt`** | 🔴 **كود الـ Java اللي بتجرّب عليه.** اكتب فيه أي جُمل عايز تشوف الأداة هتقطّعها إزاي |
| `run.bat` | التشغيل على ويندوز — دبل كليك |
| `run.sh` | التشغيل على ماك/لينكس |
| `../javacc.jar` | الأداة نفسها، في الروت فوق. **متلمسهاش** |
| `build/` | بيظهر بعد أول تشغيل. **كله مولّد** — متعدّلش فيه ومتسلّمهوش |

### `test.txt` — ده مدخل البرنامج

الـ lexer **بيقرا الملف ده**. اللي جواه دلوقتي:

```java
int x = 42;
float rate = 3.14;
float avogadro = 6.02E+23;
String msg = "Hello World";
int whiles = 0;
for (i = 0; i < 10; i++) { total += i; }
if (a >= b) { System.out.println(msg); }
```

**ده كود Java عادي.** وشغلة الأداة إنها تقطّعه لـ tokens وتطبعهم.

⚠️ **ومفيش حاجة مقدّسة في السطور دي.** امسحها، غيّرها، زوّد عليها. كل ما
تخلّص قاعدة، حط سطر يختبرها وشغّل. لو عايز تشوف `3.14` بتطلع إزاي، سيب
سطر واحد في الملف وخلاص.

**وعايز ملف تاني بدل ما تلخبط ده؟** اعمل ملف جديد بأي اسم وشغّل:

```
run.bat Lexer.jj my-test.txt
```

اسم الملف **مش مكتوب جوه الكود**، انت بتبعته في الأمر.

## الستة أماكن

مكتوبين في `Lexer.jj` كده:

```
/* ---- ٣ ---------------------------------------------- */
```

| | المطلوب | الدرجة |
|---|---|---|
| **١** | كمّل `SKIP` — المسافة والـ tab والسطر الجديد والـ carriage return | ٤ |
| **٢** | كمّل الكلمات المحجوزة — ١٧ كلمة ناقصة | ٥ |
| **٣** | اكتب `IDENTIFIER` | ٦ |
| **٤** | اكتب `NUMBER` — رقم صحيح وبعده كسر **اختياري** | ٧ |
| **٥** | اكتب `STRING_LITERAL`، وبعدين **هات الباگ** | ٨ |
| **٦** | العلامات اللي من حرفين، والأُسّ | **بدون درجات** |

**٤ + ٥ + ٦ + ٧ + ٨ = ٣٠**

املاهم بالترتيب، **وشغّل بعد كل واحد** عشان تشوف الفرق.

## ملف الوصف مقسوم

| البلوك | إيه فيه |
|---|---|
| `SKIP` | اللي **بيترمي** — مسافات وكومنتات |
| `TOKEN` keywords | الكلمات المحجوزة |
| `TOKEN` identifiers | أسماء المبرمج |
| `TOKEN` numeric constants | `42` · `3.14` |
| `TOKEN` string constants | `"hello"` |
| `TOKEN` special characters | `;` · `(` · `{` — بتفصل وبتجمّع |
| `TOKEN` operators | `+` · `=` · `<=` — **بتعمل حاجة** |

وستة التصنيفات دول هما **نفس أقسام جدول الرموز** اللي الجزء ٠٢ هيطبعها.

## صيغة التعبيرات

| بتكتب | معناها |
|---|---|
| `"if"` | النص ده بالظبط |
| `["0"-"9"]` | **حرف واحد** من المدى |
| `["+","-"]` | **حرف واحد** من القايمة |
| `~["x"]` | أي حرف **ما عدا** x |
| `~[]` | أي حرف خالص |
| `A B` | A وبعده B |
| `A \| B` | A أو B |
| `( A )*` | صفر أو أكتر |
| `( A )+` | واحد أو أكتر |
| `( A )?` | موجود أو لأ |

⚠️ `["0"-"9"]` لوحدها **حرف واحد**. عشان تاخد أكتر، حط `+` أو `*` بعدها.

⚠️ و `~["x"]` **بتشمل السطر الجديد**. فلو كتبت قاعدة كومنت بـ `~[]` من غير
استثناء، هتبلع الملف كله.

## لو وقفت

| المشكلة | الحل |
|---|---|
| `javac is not recognized` | الـ JDK مش مركّب، أو مقفلتش الـ terminal بعد ما ركّبته |
| `javacc refused the file` | غلطة في `Lexer.jj` — الرسالة فيها رقم السطر. غالباً `>` ناقصة أو فاصلة زيادة |
| النافذة بتقفل بسرعة | شغّله من terminal: `cmd` في المجلد وبعدين `run.bat` |
| `Lexical error` | **ده المتوقّع في الأول** |

ولو لسه واقف — **اسأل في جروب التليجرام ومعاك صورة الشاشة.**
